

\# AI WhatsApp Sales Agent



\## Project Overview



An AI-powered WhatsApp Sales Agent developed using

n8n for a fictional travel and tour company called

WanderWise Tours.



\## Business Objective



The system will:



\- Receive customer enquiries through WhatsApp.

\- Understand customer requirements using AI.

\- Provide relevant tour and travel information.

\- Collect and manage customer information.

\- Qualify and score potential customers.

\- Automate customer follow-ups.

\- Schedule appointments.

\- Escalate conversations to human sales representatives.



\## Technology Stack



\- n8n

\- WhatsApp Cloud API

\- OpenAI API

\- PostgreSQL

\- Google Calendar

\- Git and GitHub
